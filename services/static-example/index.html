Static example

Hola, soy un ejemplo estático para probar reglas que hacen match con el request path mediante una expresión regular.

Hallo, ich bin ein statisches Beispiel, um Regeln zu testen, die mit dem Request-Pfad über einen regulären Ausdruck übereinstimmen.

To try a rule in cloudflare

      
        $ cloudflared tunnel ingress rule https://static.example.com/images/dog.gif
        Using rules from ~/cloudflared_config.yaml
        Matched rule #2
        Hostname: static.example.com
        path: /images/*\.(jpg|png|gif)

Rule to match

      
      # Rules can match the request's path to a regular expression:
    - hostname: static.example.com
      path: /images/*\.(jpg|png|gif)
      service: https://machine1.local:3000
docker compose up --build -d --force-recreate static-example
